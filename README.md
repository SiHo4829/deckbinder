## 📌 프로젝트 소개 (About)

**덱바인더(DeckBinder)**는 TCG(Trading Card Game) 시장의 무분별한 투기 및 되팔이(리셀) 행위로 인한 유저 피로도를 해소하고, 순수한 **플레이어(Player)**와 **수집가(Collector)**가 합리적인 가격에 카드를 구하고 덱을 즐길 수 있도록 돕는 유틸리티 웹 서비스입니다.

스니커덩크(SNKRDUNK) 방식의 단일 거래 기준가를 기반으로 일본 주요 중고 거래 플랫폼(메르카리, 라쿠마, 야후옥션)의 실시간 매물을 직관적으로 탐색하며, 덱 빌딩 및 첫 손패 시뮬레이션을 제공합니다.

---

## 💡 핵심 기능 (Key Features)

### 1. 🎴 카드 도감 & 스마트 검색 (Card Encyclopedia)
* **상세 필터링:** 속성, 레어도, 발매 팩, TCG 전문 키워드(드로우, 에너지 가속 등) 조합 검색
* **대체 카드 그룹화:** 동일/유사한 효과를 가진 대체 가능한 카드 묶음 제공
* **단일 기준가 표기:** 주식형 그래프를 배제하고 최신 거래 기준가 1개만 심플하게 제공

### 2. 🃏 덱 레시피 & 시뮬레이터 (Deck Builder & Simulator)
* **우승 덱 & 메타 레시피:** 대회 우승 덱 및 티어별 대표 덱 레시피 분석
* **첫 손패 드로우 테스트:** 5장 드로우 및 멀리건(셔플) 기능으로 덱 구성 확률 실시간 테스트
* **덱 소스 크롤링 연결:** 덱 완성에 필요한 주요 카드의 직구 최저가 검색 모듈 즉시 연동

### 3. 🔍 일본 중고 매물 실시간 크롤러 (Japan Live Crawler)
* **대상 사이트:** 메르카리(Mercari), 라쿠마(Rakuma), 야후옥션(Yahoo Auctions)
* **되팔이(리셀러) 방지 장치:**
  * **1회 1장 검색 제한:** 대량 스캔 및 매크로 무력화
  * **Rate Limit:** 1분 내 최대 3회 검색 제한
  * **의도적 프로세스 연출:** 8~12초 동안 진행 단계(Progressive Loading)를 연출하여 대량 수집 방지
* **수집가 옵션:** A급, 미개봉, PSA/BGS 등급 카드 전용 필터 기본 제공

### 4. 📚 디지털 개인 컬렉션 (Personal Collection)
* **가상 3공 바인더:** 소장 카드 및 위시리스트(Wishlist) 시각화 관리
* **컬렉션 총 가치 계산:** 단일 기준가 연동을 통한 내 소장품 총액 자동 산출
* **SNS 공유:** 외부 커뮤니티 및 X(트위터) 공유용 바인더 링크 생성

## 🛠 기술 스택 (Tech Stack)

### Frontend
* **Framework:** Next.js / React
* **Styling:** Tailwind CSS
* **State Management:** Zustand / TanStack Query (React Query)

### Backend & Database
* **Database & Auth:** Supabase (PostgreSQL + OAuth)
* **Proxy & Scraping:** Cloudflare Workers (CORS 회피 및 브라우저 클라이언트 연산 분산)
