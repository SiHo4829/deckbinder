## 📌 프로젝트 소개 (About)

**덱바인더(DeckBinder)**는 TCG(Trading Card Game) 플레이어와 컬렉터를 위한 유틸리티 웹 서비스입니다.
카드를 찾고, 덱을 짜고, 모은 것을 정리하는 일을 한자리에서 할 수 있게 만드는 것이 목표입니다.

**대상 게임은 포켓몬 카드 게임과 원피스 카드 게임 2종입니다.**
현재 카드 데이터가 들어와 있는 것은 **원피스(한국판·일본판)**이고, 포켓몬은 게임 규칙만 정의된 상태입니다.

### 이 서비스가 하지 않는 것

방향을 분명히 하려고 적어 둡니다. 아래는 "아직 안 만든 것"이 아니라 **만들지 않기로 한 것**입니다.

* **가격을 다루지 않습니다.** 화폐 단위 표기 · 변동 차트 · 등락률을 만들지 않습니다.
* **중고 거래 매물을 중개하거나 검색해 주지 않습니다.**
* 컬렉션의 가치는 가격이 아니라 **자체 수집 점수**로만 표현합니다. 이 점수는 우리가 만든 값이고, 공식 희귀도 등급과 다릅니다.

## 💡 기능 (Features)

### 구현된 것

#### 🎴 카드 도감 & 검색
현재 **원피스 카드 게임 3,139장 · 40세트**가 들어와 있습니다.

* **조합 필터:** 속성 · 레어도 · 카드 타입으로 검색
* **같은 카드의 다른 버전:** 패러렐 · 알트아트 등 다른 인쇄본을 기본 코드(`base_code`)로 묶어서 제공
* **자체 수집 점수:** 카드 상세에서 입수 난이도를 우리 기준으로 환산해 배지로 표시. **근거를 함께 보여 주고, 우리가 만든 값이라는 고지를 답니다**

#### 🔒 관리자
* 카드 · 세트 · 키워드 · 뉴스 관리

### 만들고 있는 것

| 기능 | 상태 |
|---|---|
| **덱 빌더 & 첫 손패 시뮬레이터** | 규칙 · 확률 · 멀리건 로직은 순수 함수로 구현 완료. **화면 미구현** |
| **디지털 바인더 (도감 완성도)** | 브라우저 로컬 저장 기반 체크리스트. 코드 완료, **화면 미구현** |
| **카드 이미지 리버스 프록시** | Cloudflare Worker 구현 완료. **미배포** |
| **TCG 키워드 조합 검색** | 코드·화면 완료. **태깅된 키워드가 아직 0건이라 필터에 뜨는 항목이 없습니다** |
| **뉴스** | 코드·화면 완료. **게시된 글이 아직 없습니다** |
| 세트별 카드 목록 | 설계 확정, 미구현 |
| 소셜 로그인 · 서버 컬렉션 · 바인더 공유 | 미착수 |

## 🛠 기술 스택 (Tech Stack)

### Frontend
* **Framework:** Next.js 16 (App Router · RSC) / React 19
* **Styling:** Tailwind CSS v4 · shadcn/ui
* **State:** Zustand (클라이언트) / TanStack Query (서버)

### Backend & Database
* **Database:** Supabase (PostgreSQL · RLS)
* **Edge:** Cloudflare Workers — **카드 이미지 리버스 프록시**
  * 외부 사이트 접근은 워커에서만 합니다. Next.js 앱은 대상 사이트에 직접 접근하지 않습니다.

### 테스트
* Vitest (단위 · 컴포넌트) · Playwright (E2E)
