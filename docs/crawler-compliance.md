plan.md §9.4 요구 문서. **대량 수집을 실행하기 전에** 대상별 이용약관 검토 결과를 여기에 기록한다.
관측 사실과 법적 판단을 분리해 적는다. 아래 "관측"은 2026-08-23 실측이고, "약관 검토"는 아직 수행되지 않았다.

## 1. pokemoncard.co.kr (포켓몬코리아 공식) — T1.6b 대상

### 관측 (2026-08-23)

| 항목 | 결과 |
|------|------|
| `robots.txt` | **`User-agent: * / Allow: /`** — 전체 크롤 허용 명시 (초기 기록의 "없음"은 확인 누락으로 인한 오류였다) |
| 렌더링 | 서버 렌더링 HTML |
| 세트 선택 옵션 | 549개 (코드 없이 한국어 세트명만) |
| 목록 페이지 | 카드 **이름·번호가 마크업에 없음**. 상세 링크(`/cards/detail/{내부ID}`)와 이미지만 존재 |
| `GoodsName` GET 필터 | 적용되지 않음 (기본 목록이 그대로 반환됨) |
| 내부 API `/v2/ajax2_dev2` | POST. 세션/JS 컨텍스트 없이는 빈 응답 |
| 카드 상세 페이지 | 한국어 카드명 · 번호(`001/081`) · 레어도 · 세트명 포함 |

### 코드 매칭 경로 (검증 완료)

한국 사이트는 세트 **코드**를 노출하지 않지만, TCGdex `ko`가 세트 코드↔한국어 세트명 매핑을 갖고 있어 다리가 된다.

* TCGdex ko 세트명 ↔ KR 사이트 세트명 매칭률: **93 / 95 (98%)**
  (「…」 안쪽을 정규화해 비교. 실패 2건: `S8a` 25th Anniversary, `S7R` 창공의스트림)
* **상한:** TCGdex ko 세트가 95개뿐이라 우리 183개 세트 중 **약 51%**만 커버 가능

### 카드 이미지 (구성 가능)

```
https://cards.image.pokemonkorea.co.kr/data/wmimages/{SERIE}/{SET}/{SET}_{NNN}.png
```

* `SERIE`는 TCGdex의 `serie.id`와 일치한다 (`SV`, `SM`). **예외: `M` 시리즈는 `MEGA`** 로 쓴다.
* 존재하지 않는 조합은 `415`를 반환한다. 세트별 커버리지가 부분적이므로 **URL마다 HEAD 확인이 필요**하다.
* 경로명이 `wmimages`(워터마크 이미지)다. **포켓몬코리아 저작물이다.**

### 수집 실행 (사용자 승인, 2026-08-23)

`robots.txt`가 전체 허용을 명시하므로 수집을 실행했다. 그럼에도 아래 제약을 스스로 건다.

| 항목 | 값 |
|------|-----|
| 동시 요청 | 5 |
| 요청 간 간격 | 120ms |
| User-Agent | `deckbinder/0.1 (card catalog; github.com/SiHo4829/deckbinder)` — 신원과 연락처 노출 |
| 재실행 | upsert 멱등. 필요한 범위만 재수집 |

### 남은 미해결

1. **이용약관 본문 검토는 여전히 미수행.** `robots.txt` 허용은 크롤러 접근에 대한 신호일 뿐, 데이터·이미지의 이용 범위를 규정하지 않는다.
2. **이미지 저작권(§9.3):** 저장하는 값은 포켓몬코리아 CDN URL이다(파일 복제 아님). 재배포·캐싱 방침은 미확정.
