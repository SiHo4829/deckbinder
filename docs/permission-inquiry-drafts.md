# 카드 정보 이용 문의 메일 초안

`docs/crawler-compliance.md`(2026-08-25 약관 검토)의 후속. 네 곳 모두 재사용 조건에
**「事前許諾がない限り」·「승낙 없이」·「無断」**을 달았으므로, 허락을 받으면 문언상 열린다.

`[이름]` · `[이메일]` · `[사이트 주소]`를 채워서 보낸다. 사이트 주소는 아직 배포 전이면
비워도 되고, "현재 개발 중"으로 두어도 된다.

## 보내는 순서

원피스는 **한국·일본이 한 세트**다. 한국 사이트에서 한국어명을, 일본 사이트에서
일본어명을 얻어야 카드 한 장이 완성된다 — `cards.name_ja`가 `not null`이고
시세 조회의 유일한 키이기 때문이다(마이그레이션 002). 둘 중 하나만 허락받으면 반쪽이다.

| 순위 | 대상 | 이유 |
|------|------|------|
| 1 | 원피스 한국 (`card@xosoft.kr`) | 지금 넣으려는 ST-01·ST-02의 한국어명 |
| 2 | 원피스 일본 (반다이) | 같은 카드의 **일본어명**. 없으면 등록 자체가 불가능 |
| 3 | 포켓몬코리아 | 포켓몬 도입 시 |
| 4 | 포켓몬 일본 (주식회사 포켓몬) | 포켓몬 일본어명 |

## 공통 원칙

- **광고 계획을 숨기지 않는다.** 숨기고 받은 허락은 나중에 무효가 된다.
- **자동 수집 가부를 따로 묻는다.** "가능"이 나오면 입력 비용 문제가 통째로 사라진다.
- **출처 표기 방식을 묻는다.** 실제로 "이렇게 표기하면 된다"는 답이 오는 경우가 많다.
- **"허용되지 않으면 조정하겠다"를 넣는다.** 답장 확률이 올라간다.

## 1. 원피스 카드게임 한국 — `card@xosoft.kr`

**제목:** [문의] 원피스 카드게임 카드 정보의 팬 서비스 활용 범위 문의

```
안녕하세요.

원피스 카드게임 팬 서비스를 개인적으로 개발 중인 [이름]입니다.

카드를 이름·효과·레어도로 검색하고 덱 구성을 돕는 웹 서비스를 준비하고
있습니다. 현재 개발 단계이며 아직 공개하지 않았습니다.

카드 정보를 서비스에 담기에 앞서 허용 범위를 확인하고자 문의드립니다.
아래 항목에 대해 가부를 알려주시면 그에 맞춰 진행하겠습니다.

1. 공식 사이트(onepiece-cardgame.kr)에 게재된 카드 정보 — 카드명, 효과
   텍스트, 레어도, 카드 종류 등 — 를 자체 데이터베이스에 저장하여
   검색·필터 기능으로 제공해도 되는지

2. 위가 가능하다면, 정보를 자동으로 수집(크롤링)해도 되는지, 아니면
   수작업 입력만 허용되는지

3. 카드 이미지를 공식 사이트의 이미지 주소를 그대로 참조하는 방식으로
   노출해도 되는지 (이미지 파일을 자체 서버에 저장하지 않는 방식입니다)

4. 향후 서비스 운영비 충당을 위해 광고를 게재할 경우 위 사항에 제약이
   생기는지

5. 이용이 허용되는 경우, 사이트에 표기해야 할 저작권 문구나 출처 표기
   방식이 있는지

공식 사이트에서 이용약관이나 저작권 관련 안내를 찾지 못해 직접 여쭙게
되었습니다. 허용되지 않는 범위가 있다면 그에 맞춰 서비스를 조정하겠습니다.

답변 기다리겠습니다. 감사합니다.

[이름]
[이메일]
```

## 2. 원피스 카드게임 일본 (반다이)

문의 창구는 반다이 공식 문의 폼을 확인한다. 이 사이트는
「すべての画像・テキスト・データの無断転用、転載をお断りします」를 명시하고 있으므로,
**그 문구를 읽었음을 밝히고 허락을 구하는 형식**으로 쓴다.

**件名:** カードデータの利用許諾に関するお問い合わせ（韓国のファンサイト運営者）

```
ワンピースカードゲーム ご担当者様

突然のご連絡失礼いたします。
韓国でワンピースカードゲームのファン向けウェブサービスを個人で開発して
おります、[이름]と申します。

カードを名前・効果テキスト・レアリティなどで検索し、デッキ構築を支援する
サービスを準備しております。現在は開発段階で、まだ公開しておりません。

公式サイトに「すべての画像・テキスト・データの無断転用、転載をお断りします」
と記載されていることを確認いたしました。そのため、事前に許諾の範囲を
確認させていただきたく、ご連絡いたしました。

下記についてご回答いただけますと幸いです。

1. 公式サイト(onepiece-cardgame.com)に掲載されているカード情報
   （カード名、効果テキスト、レアリティ、カード種類など）を自社データ
   ベースに保存し、検索・フィルタ機能として提供することは可能でしょうか。

2. 上記が可能な場合、情報を自動で収集（クローリング）してもよろしい
   でしょうか。それとも手作業での入力のみ許容されますでしょうか。

3. カード画像について、公式サイトの画像URLを直接参照する形での表示は
   可能でしょうか。（画像ファイルを自社サーバーに保存しない方式です）

4. 将来的に運営費のため広告を掲載する場合、上記に制約が生じますでしょうか。

5. ご許諾いただける場合、サイトに記載すべき著作権表示や出典表記の形式が
   ございましたらご教示ください。

なお、日本語のカード名は、カードの同定および日本国内の中古市場における
相場情報の参照に使用する予定です。韓国語版のカード名のみでは同一カードの
特定が困難なためです。

許諾いただけない範囲がございましたら、それに合わせてサービスを調整いたします。

お忙しいところ恐れ入りますが、ご確認のほどよろしくお願い申し上げます。

[이름]
[이메일]
```

**제목:** [문의] 포켓몬 카드게임 카드 정보의 팬 서비스 활용 범위 문의

5. 이용이 허용되는 경우 표기해야 할 저작권 문구가 있는지

허용되지 않는 범위가 있다면 그에 맞춰 서비스를 조정하겠습니다.

## 회신을 받으면

내용을 `docs/crawler-compliance.md`의 해당 사이트 절에 **원문 그대로 인용**하고
회신 날짜를 남긴다. 구두·전화 회신이라면 그 사실과 일시를 적는다.
회신 내용이 약관 본문보다 우선하므로, 그 시점에 §4.4의 원천 방침과
§9.1(애드센스) · §9.4(이미지)를 함께 재검토한다.
